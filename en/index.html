FABRIC API JAVA 21 PROCEDURAL RENDERING

Personal project in development: aura_mod explores programmable abilities, in-game configuration interfaces, and procedural visual effects with Fabric. It showcases my technical and creative approach to complex mechanics; it is not client work. When creating a world, the player selects a specialty (here, Body) and generates a dynamic pixel-art aura that follows their movements.

  • [K] Editor & Training Mode: An in-game interface for assembling spell pages, with built-in tutorials and an unlimited-aura sandbox for testing mechanics.
  • [X] In-game Page Switching: Switch between Combat (physical enhancement and damage absorbed using aura reserves) and Movement (directional mobility and dashes).
  • Vows & Restrictions: Spell logic with variables and strict conditions (for example, grow/shrink using keys 1/2, or slow an opponent only below five hearts). Breaking a vow triggers an immediate penalty (here, the player's death).
  • [+] Architecture: Code structured around an in-game spell editor and modular procedural rendering.
