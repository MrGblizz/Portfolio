# MG — Creative Developer Portfolio

A lightweight, English-language personal freelance portfolio focused on Minecraft Fabric gameplay systems, procedural effects and video editing.

## Publish using GitHub Pages

In this public repository, go to **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)** and save. The expected URL, once GitHub Pages is enabled, is `https://mrgblizz.github.io/Portfolio/`.

## Contact

Use the website's **public GitHub issue** enquiry link or the linked profile. Do **not** share private client details in a public issue. Replace this with a dedicated professional email once one is ready.

## Evidence and accuracy

This is a personal, ongoing Minecraft project, with a block-based editor and runtime code, and experimental aura VFX. The site does not promise that every feature works in release builds, and it does not claim professional client credits. Game footage and a recent editing showreel remain to be added.
